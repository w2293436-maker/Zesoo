# 择书Zesoo — 开发需求文档

## 项目概述
**择书Zesoo** 是一款 AI 驱动的书籍精读报告生成工具。用户上传 PDF/TXT/DOCX 文件，AI 自动识别章节并逐章深度分析，生成结构化精读报告，支持导出 Word 文档。

## 目标用户
- 需要快速提炼书籍重点的读者
- 希望获得结构化读书笔记的学习者
- PC 网页端 + 手机端均可使用

## 功能需求

### F1. 文件上传
- 支持拖拽或点击上传
- 格式：PDF / TXT / DOCX
- 大小限制：50MB
- 自动识别文件类型并解析

### F2. AI 精读分析
- 自动识别书籍章节/小节结构
- 逐章深度分析，不限制提取数量
- 每章提取五大维度：
  1. 章节总结（该章内容概括）
  2. 核心观点（所有观点，不限数量）
  3. 金句摘录（原文原句）
  4. 方法论（方法/技巧/框架+步骤）
  5. 启示与行动建议

### F3. 报告预览
- 左侧章节导航 + 右侧报告正文
- 按章节切换查看
- 桌面端侧边栏、移动端弹窗导航

### F4. 报告导出
- 导出为 Word (.docx) 格式
- 完整保留所有章节内容
- 中文排版优化

### F5. 进度反馈
- SSE 实时进度推送
- 显示当前处理阶段和百分比
- 步骤：解析文件 → 识别章节 → 逐章分析 → 组装报告

### F6. 响应式设计
- PC 桌面端完整布局
- 手机端自适应（侧边栏变为弹窗）
- 灰白极简风 + 蓝色主色调

## 非功能需求
- AI 服务：DeepSeek API（deepseek-chat 模型）
- 文本解析：pdfplumber + PyPDF2 双引擎 + DeepSeek Vision OCR
- 公网部署，永久在线
- API Key 仅存后端，不暴露前端
